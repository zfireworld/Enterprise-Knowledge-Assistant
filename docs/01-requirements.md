# 需求

## 用户与目标

员工输入制度或产品问题及可选对话历史，从带文档 ID 和版本日期的资料中找到可核对的答案；系统返回回答、文档引用、原文、资料缺口和任务状态。

## 范围

提供文档检索和片段读取两个工具，由模型根据观察决定补充检索、读取、追问或结束。冲突无法消解时保留双方证据并请求确认，不按日期或排名擅自决定优先级。工具调用次数受限，达到上限应明确未完成；工具或模型不可用时不得编造答案。

## 成功标准与非目标

测试覆盖明确答案、文档冲突、资料外问题、相似问法、上下文追问、工具失败，以及替换文档后的变化。至少两条真实模型路径应体现对工具结果的不同后续动作；Mock 只验证流程。题目不要求生产部署、多 Agent 或完整权限体系。

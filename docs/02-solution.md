# 方案

CLI 组装模型、仓库和服务。服务反复将历史与观察结果交给模型，执行 `search_documents` 或 `read_passage`，直到模型结束或工具调用达到上限。引用必须是本轮已读取片段的非空子串。工具故障返回未完成。

本地仓库按主题词检索；Milvus 仓库复用 BGE 混合检索、HyDE 和 RRF。LangChain Core 1.2.19 与 langchain-openai 1.1.11 用于调用兼容模型；项目已安装 LangGraph 1.1.2，但本链路使用显式循环。Mock 是确定性规则，用于验证流程。模型使用 JSON 动作协议，工具执行和上限由服务控制。

检索可能漏召回；模型可能误判冲突或生成不受原文支持的推论。子串校验不能替代语义判断或权限控制。

# 复盘与后续工作

主要难点是让原有商品检索支持制度问答：既要复用向量召回，又要保留文档 ID、版本及可核对的原文。Milvus 的旧数据缺少部分元数据、不同版本的 Hit 结构又有差异，曾导致检索结果转换失败；通过增加存在性过滤和真实返回结构测试修复。旧资料没有可靠页码时，不应猜测位置。

真实模型最初对冲突制度暗示较新日期可能优先，但资料没有这样的依据；收紧提示词后，新一轮真实模型与 Milvus 测试列出了两方规定。一次追问中模型引用了没有读取过的候选片段，引用校验反馈后才补读并完成；因此系统保留了明确的读取工具和可追溯的引用校验。

当前仍有边界：动态分差截断可能漏掉冲突证据；引用子串匹配不能证明回答的所有推断都成立下一步应扩大冲突与改写评估集、改进排序和状态判定、评估语义支持度，并按需要增加持久化任务队列。
